## Install apple-hig

[apple-hig](skills/apple-hig/README.md) helps coding agents design and review native Apple interfaces using local HIG guidance. It covers platform conventions, component choices, Liquid Glass, and accessibility, with official sources for updates.

Install with the [skills CLI](https://github.com/vercel-labs/skills) used by [skills.sh](https://skills.sh/):

```bash
npx skills add xinyao27/mybrain --skill apple-hig
```

Run it in your project and select your agent. For a global Codex installation without selection prompts:

```bash
npx --yes skills add xinyao27/mybrain --skill apple-hig --global --agent codex --yes
```

See the [skill README](skills/apple-hig/README.md) for requirements, usage examples, updates, and licensing.
