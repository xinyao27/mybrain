# GC 极简 Zine 海报

把用户的内容转化为：

1. 最终图像生成提示词；以及
2. 使用该提示词生成的位图图像。

## 模式策略

所有生成任务都使用**标准模式**。使用本 SKILL.md 中的标准模式提示词编译器，把用户内容转换为紧凑、可成像且高保真的提示词。如果用户要求更高质量，按照下列规则强化提示词。

## 标准模式提示词编译器

默认只编译会直接成为最终图像像素的内容。

### 提示词编译器使用的视觉规则

使用以下规则组作为提示词素材：

- **风格总述：** 只使用视觉身份与反向身份：诗意极简纸张海报、大面积留白、旧纸、小型视觉锚点、稀疏文字、一个清晰的高饱和色彩锚点，以及 zine／编辑气质。
- **核心视觉规则：** 使用可具体渲染的画布、构图、背景、图像锚点、排版、色彩、纹理、光线和情绪规则。
- **稳定共性：** 作为不可妥协的必备项：竖向 3:5 纸张画布、小型视觉组、扫描纸张视角、旧印刷瑕疵、衬线体或打字机字体，以及缩略图尺寸下仍可见的饱和色彩锚点。
- **可替换变量：** 作为可选槽位：物件、照片／剪贴／剪影／色块类型、强调色、文字行、日期／天气、位置和纸张色调。
- **反向约束：** 作为负面提示词素材。
- **提示词结构模板：** 使用其字段顺序，不照抄示例措辞。

默认提示词不要包含：

- 源路径、样本数量、README／元数据备注或分析范围
- 关于这种风格为何有效的长篇解释
- 特定样本中的签名、日期、说明文字、物件或文本
- 对示例提示词逐句模仿
- 检查清单式措辞，除非它能转化为具体视觉约束

### 第一性原理提示词字段

每条标准模式提示词都必须按以下顺序回答这些渲染问题：

1. **画布：输出画面和基础表面是什么？**
   - 竖向 3:5 手机海报；全画幅旧纸；无边框、无样机。

2. **注意力几何：视线落在哪里，有多少留白？**
   - 70%–90% 为纯纸张；一个约占 8%–25% 的视觉组；放在中央、中上部、中下部、左下或右上；不要贴边。

3. **图像锚点：唯一可成像的主体是什么？**
   - 把用户主题转换为一个物件、碎片、照片裁切、标本、剪贴、剪影、旧印刷插图、纹理窗口或小型概念关系。

4. **锚点处理：什么材料工艺让锚点融入纸张？**
   - 灰度照片和纸张碎片可使用低对比度、复印柔化、撕边、柔化边缘、半色调、扫描线、孔版印刷颗粒、影印磨损、油墨渗化或轻微套印错位。不要降低选定色彩锚点的饱和度或对比度。

5. **排版系统：文字在视觉上如何表现？**
   - 小号衬线体、打字机体或等宽字体；一句简短可读文字；可选极小日期／地点／天气和签名；半可读微缩文字或碎片字母；文字可以漂移、贴近图像边缘、模糊或错位。

6. **色彩逻辑：克制的强调色策略是什么？**
   - 纸张色调和灰／黑色承托一个明确无误的高饱和色彩锚点。优先钴蓝或群青；也可轮换青色、紫色、洋红粉、柠檬黄、梨绿、橙色或番茄红。色彩可以是主体、平面剪影、不规则剪贴、实质性色块、局部彩色照片区域或粗体碎片字。不要自动把它缩减为微小圆点或细线。

7. **复制纹理：什么印刷／扫描工艺定义整张图？**
   - 平面正交的扫描纸张外观；哑光吸墨纸；漫射光；中低对比度；无硬阴影；无 3D 深度。

8. **情绪温度：观者在辨认物件前应先感受到什么？**
   - 安静、诗意、怀旧、稀疏、日记感、档案感、疏离、记忆感，以及日系／韩系独立 zine 或极简编辑气质。

9. **硬性排除：绝不能出现什么？**
   - 满版场景、商业大标题、产品广告、Logo／行动号召、光泽样机、干净 UI 白底、电影式布光、3D、霓虹、可爱卡通、戏剧化时尚编辑、密集剪贴簿、过多色彩、长而规整的文字。

### 标准色彩引擎

本节定义标准模式的色彩策略。

- 默认使用一个清晰可见、饱和且不透明的彩色油墨锚点。使用类似“完全饱和的钴蓝孔版油墨”“不透明的群青剪贴”“鲜艳梨绿色平面剪影”或“干净的番茄红印刷色块”等措辞。
- 纸张、灰度照片、微缩文字和次要标记应保持克制。即使加入颗粒、半色调、油墨渗化或套印错位，也要保留色彩锚点的饱和度。
- 高饱和区域应约占整个画布的 0.8%–2.5%，或占小型视觉组的 15%–35%。以缩略图查看时仍必须清晰可见。
- 色彩可以承载主体本身。优先选择彩色树木、水果、贝壳、花朵、几何剪贴、窗户、海报碎片或图像面板，而不是灰色物件配一个彩色套准点。
- 单张图默认使用具有实质面积的色彩锚点。批量生成时，至少 60% 的图像应使用彩色主体、剪贴或色块；其余图像可以用圆点、细线或彩色文字形成节奏。
- 除非用户明确要求单色、柔和或粉彩输出，否则不要使用“近单色”“无强烈强调色”“浅色强调”“柔和强调”“褪色强调”或“粉彩强调”等描述。
- 不要把整张图描述为低饱和。只把“低对比度”和“柔和灰度”用于纸张、照片和次要油墨。
- 每张图只使用一种主要高饱和色。仅当它能辅助主体且不会让海报显得商业化多彩时，才允许加入极小面积的第二种色相。

### 标准提示词结构

把最终标准模式提示词写成四个紧凑段落：

1. 画布＋纸张＋留白＋视觉组尺寸／位置
2. 主体隐喻＋锚点类型＋锚点处理
3. 排版＋强调色策略＋印刷瑕疵
4. 平面扫描情绪＋排除项

在第 3 段明确写出高饱和色相、材料形态和大致视觉占比。这一结构比逐条复述所有规则更重要。优先写具体、可成像的提示词，不写冗长的风格论文。

## 变化引擎

写提示词前，从每个轴中选择一个选项。随机变化必须改变视觉语法，而不仅是位置。如果近期输出使用了相同布局或锚点，选择不同方案。

### 布局家族

- **中央碎片：** 位于中央的微小图像或物件，四周保留空气感
- **左下漂浮：** 小型锚点位于左下象限，上方大面积留白
- **右上色块：** 右上放置小型色块／照片块，文字松散漂移
- **双面板：** 两个略微重叠或相邻的小面板，中间留窄缝
- **不规则剪贴：** 承载图像或文字的撕纸／有机纸形
- **文字主导：** 排版是主要视觉锚点，图像居次或缺席
- **圆点轨道：** 圆点、字母或细线围绕小主体形成轨道
- **单一标本：** 一个孤立物件或标记，几乎没有辅助图形

### 图像锚点

- 微小褪色照片
- 撕纸剪贴
- 平面剪影
- 纯色色块
- 旧印刷插图
- 物件标本
- 半透明几何叠层
- 抽象纹理窗口

### 排版模式

- 碎片化漂浮字母
- 贴着图像边缘的短句
- 带日期／天气的档案微缩文字
- 对角散落词语
- 低对比度灰色幽灵文字
- 以粗糙凸版字为主体
- 色块或剪贴内部的文字
- 几乎无字，只有极小说明

### 纹理模式

- 影印柔化
- 孔版印刷颗粒
- 凸版油墨渗化
- 半色调劣化
- 胶片颗粒照片
- 扫描噪点与纸张纤维
- 旧纸斑驳
- 选定文字的轻微运动模糊

### 情绪模式

- 安静
- 夏日
- 独处
- 童年
- 海边
- 午后
- 夜晚
- 记忆
- 轻微超现实

## 工作流

1. 确定模式。
   - 使用标准模式。

2. 解析用户内容。
   - 识别核心主体、情绪、用户提供的确切文字、可能的视觉隐喻，以及任何参考图像的用途。
   - 对文章或复杂想法提取一个核心可成像概念，不要概括整篇论述。
   - 如果用户没有提供画面文字，创作一句简短而诗意的英文或中文。

3. 选择变化配方。
   - 在标准模式中，从变化引擎选择布局、图像锚点、排版、纹理和情绪，再通过标准色彩引擎选择颜色。除非用户明确要求，否则不要选择“近单色”。
   - 不要默认使用“微小照片＋蓝色圆点＋微缩文字”，除非它确实适合。
   - 如果配方过于密集，先简化排版或色彩处理。

4. 编写最终图像提示词。
   - 在标准模式中，使用标准模式提示词编译器，把用户内容编译为四段结构：画布、锚点、排版／强调色／印刷、平面扫描情绪与排除项。
   - 只有在确有帮助时才指定画面中的精确文字。文字应保持简短，因为图像模型会扭曲长文本。
   - 提示词必须明确：锚点放在哪里、多大，文字如何表现，出现什么强调色，以及印刷／扫描纹理如何呈现。

5. 生成图像。
   - 默认使用内置图像生成能力。
   - 除非用户明确只要提示词，否则不要在只有提示词时停止。
   - 如果结果明显违反所选模式或配方，收紧提示词并重新生成一次。
   - 在标准模式中，以缩略图尺寸检查结果。如果高饱和锚点缺失、褪色或缩小为难以察觉的标记，使用更强的色彩措辞和更大的彩色面积重新生成一次。

6. 返回图像和提示词。

## 负面约束

始终避免：

- 满版主体或场景
- 商业海报式大标题层级
- 产品广告布局、Logo 组合、行动号召或品牌推广感
- 干净的数字 UI 背景
- 光泽纸张样机或厚重纸张阴影
- 3D 渲染、电影式布光、硬阴影、景深、霓虹、赛博朋克
- 可爱卡通、卡哇伊插图、动漫海报、戏剧化时尚编辑
- 过多物件、贴纸、颜色、说明文字或装饰纹理
- 高分辨率图库照片写实感
- 长而干净、完全可读的文字块

## 质量门槛

最终提交前检查：

- 是否使用了标准模式提示词编译器？
- 是否跨布局、锚点、排版、强调色、纹理和情绪选择了变化配方？
- 结构是否与近期可见输出有实质差异？
- 图像是否仍是稀疏的竖向纸张海报？
- 画面是否有 70%–90% 呈现为纸张？
- 主体视觉组是否约占画布的 8%–25%？
- 是否只有一个清晰视觉隐喻，而不是完整插画场景？
- 锚点是否具有旧照片、剪贴、印刷、扫描或纸张标本处理？
- 排版和微缩文字是否参与构图？
- 是否只有一种克制的强调色策略？
- 在标准模式中，高饱和色彩锚点是否在缩略图尺寸下清晰可见？
- 在标准模式中，饱和色是否约占画布的 0.8%–2.5%，或视觉组的 15%–35%？
- 在标准模式中，提示词是否避免使用“浅色”“柔和”“褪色”“粉彩”“低饱和”或“近单色”等弱化色彩锚点的措辞？
- 提示词是否避免满版、商业、3D、霓虹、电影感、卡通、可爱、品牌和通用模板审美？
- 是否实际生成了图像？
